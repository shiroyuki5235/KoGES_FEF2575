1. 현재 원고의 분석 범위 반영
현재 원고를 기준으로 주분석 네 그룹의 Model 1–4와 Table S4의 탐색적 세 그룹 Model 4/5/A/B/C 및 BMI 시간효과를 포함합니다. 기존 대상자·주분석 그룹·사건 정의는 유지합니다. Module 27–28에서 S4를 계산하고 기존 결과와 대조합니다. 로컬 재실행은 필요합니다.

2. FEF 전용 예측식은 아직 미확정
Choi 2005의 FEV1/FVC 관련 예측식을 FEF에 확대 적용하면 안 됩니다. VMAX2130 사용은 코호트 논문에서 확인되지만 해당 release의 FEF 선택식·계수·인종 보정·방문별 설정까지 특정하지 못합니다. 공개 조사지침 3종도 확인했으나 이 연결을 확정하지 못했습니다. 예측식을 새로 적용해 그룹을 바꾸지 않았습니다. 기관 답변이 없으면 한계 기술을 유지해야 하며 '확인 완료'로 지우면 안 됩니다.

3. 코드 DOI와 환경
기존 investigator-run sessionInfo에 R 4.6.1(2026-06-24 ucrt), Windows 11, survival 3.8-12가 실제 기재되어 있어 첨부본의 환경 기술은 기록과 일치합니다. 새 통합 코드는 실행 후 생성된 sessionInfo 및 package_versions로 다시 대조해야 합니다. DOI는 발급 전 상태입니다. README/CITATION.cff/보존할 버전/논문 기재 버전이 일치해야 합니다.

4. AI 활용 문구
현재 문구는 분석요청서 작성·원고 구성·언어 편집만 기재합니다. 이번 작업에는 R 코드 작성·통합·수정·정적 검토가 포함됩니다. 실제 사용 범위를 Methods에 반영하고, 연구자가 수행한 실행과 검증 책임을 구분하여 서술하는 것이 적절합니다. 실행 전에는 '저자가 새 코드를 검증했다'고 완료형으로 쓰지 않습니다.

5. S3 spline 설정
현재 'archived code should specify...'라는 미래형 문구는 최종본에 부적절합니다. 원본 코드는 splines::ns(..., df=3), 기본 intercept=FALSE, 분석 표본의 1/3·2/3 분위수 내부 knot와 관측 범위 경계를 사용합니다. 통합 코드는 실제 knot 및 boundary 값을 Spline_settings.csv에 저장합니다. 실행 후 확인하고 명시형 문구로 바꿀 수 있습니다.

6. S6 경계값 불일치의 위치
이전 출력에서 공급값 대비 재구성값의 가상 변화는 Never→Single 8명, Never→Recurrent 1명, Single→Recurrent 5명, Recurrent→Frequent 6명으로 집계되었습니다. 20명 모두 주분석 그룹은 바꾸지 않았습니다. 변화의 원인이 반올림이라고 확정할 근거는 없습니다. 통합 코드가 이 교차표를 다시 산출합니다. 실제 재실행 결과 확인 후 보충자료에 집계 설명을 추가할 수 있습니다.
