S4 신뢰구간 재현 수정

기존 BMI_TV_FEF_comparison.csv는 Original과 BMI_TV 모두 Wald 신뢰구간에 1.96을 사용합니다. 통합 코드의 qnorm(0.975)=1.9599639845와 달라 최대 약 0.00002968의 오차가 발생했습니다. 기존 History_All_contrasts.csv의 beta/SE로 계산한 이 차이가 사용자 검증표의 Original 실패 오차와 일치합니다.

Module 27/28의 S4 HR 대비 신뢰구간만 1.96으로 통일했습니다. 모형 수식, 대상자, 그룹, HR, p값 및 허용오차 0.00001은 변경하지 않았습니다.

같은 R 세션이 유지되면 새 00_Final_Analysis.R을 열어 Module 27부터 끝까지 실행할 수 있습니다. 새로 압축을 푼 폴더를 사용할 때 PROJECT_DIR을 새 패키지 폴더로 지정하고 REFERENCE_DIR <- file.path(PROJECT_DIR,"reference_results")를 갱신하세요. completion_output은 기존 실행 폴더 그대로 둡니다. 세션을 종료했다면 Module 00부터 실행합니다.

원자료로 수정본을 직접 실행하지는 않았으며, 수정 후 모든 검증의 통과 여부는 로컬 실행 결과로 확인합니다.
